# Матрицы трансформаций для пересчёта координат изображения

## Введение

Матрицы трансформаций используются для преобразования координат точек из одной системы координат в другую. В контексте работы с изображениями это позволяет:
- Переводить координаты из системы координат изображения в систему координат реального пространства (и наоборот)
- Учитывать масштаб, поворот и смещение изображения относительно реальных координат
- Выполнять выравнивание (alignment) изображения с геометрическими данными

## Математические основы

### Представление точки на плоскости

Точка на плоскости в декартовых координатах представляется как вектор:
```
P = [x, y]
```

Для удобства работы с матрицами трансформаций используется однородная система координат (homogeneous coordinates), где точка представляется как:
```
P = [x, y, 1]
```

Третья координата (обычно равная 1) позволяет объединить перенос, поворот и масштабирование в одну матрицу.

### Матрица трансформации 2D

В однородных координатах матрица трансформации имеет размер 3×3:

```
T = [a  b  tx]
    [c  d  ty]
    [0  0  1 ]
```

Где:
- `a, b, c, d` - коэффициенты для поворота и масштабирования
- `tx, ty` - коэффициенты переноса

Применение трансформации к точке:
```
[x']   [a  b  tx]   [x]
[y'] = [c  d  ty] × [y]
[1 ]   [0  0  1 ]   [1]
```

Результат:
```
x' = a·x + b·y + tx
y' = c·x + d·y + ty
```

## Базовые трансформации

### 1. Перенос (Translation)

Перенос точки на вектор `(tx, ty)`:

```
T_translate = [1  0  tx]
              [0  1  ty]
              [0  0  1 ]
```

**Пример:**
Перенос точки `(10, 20)` на вектор `(5, 3)`:
```
[1  0  5]   [10]   [15]
[0  1  3] × [20] = [23]
[0  0  1]   [1 ]   [1 ]
```

Результат: `(15, 23)`

**Свойства:**
- Сохраняет расстояния между точками
- Сохраняет углы
- Сохраняет форму объектов

### 2. Масштабирование (Scaling)

Масштабирование относительно начала координат с коэффициентами `sx` (по оси X) и `sy` (по оси Y):

```
T_scale = [sx  0   0]
          [0   sy  0]
          [0   0   1]
```

**Пример:**
Масштабирование точки `(10, 20)` с коэффициентами `sx = 2, sy = 0.5`:
```
[2   0   0]   [10]   [20]
[0   0.5 0] × [20] = [10]
[0   0   1]   [1 ]   [1 ]
```

Результат: `(20, 10)`

**Свойства:**
- При `sx = sy` - равномерное масштабирование (сохраняет пропорции)
- При `sx ≠ sy` - неравномерное масштабирование (искажает пропорции)
- Масштабирование относительно начала координат `(0, 0)`

**Масштабирование относительно произвольной точки:**

Для масштабирования относительно точки `(cx, cy)`:
1. Перенос на `(-cx, -cy)` - переместить центр в начало координат
2. Масштабирование
3. Перенос обратно на `(cx, cy)`

```
T_scale_around_point = T_translate(cx, cy) × T_scale(sx, sy) × T_translate(-cx, -cy)
```

### 3. Поворот (Rotation)

Поворот точки вокруг начала координат на угол `θ` (в радианах) против часовой стрелки:

```
T_rotate = [cos(θ)  -sin(θ)  0]
           [sin(θ)   cos(θ)  0]
           [0        0       1]
```

**Пример:**
Поворот точки `(10, 0)` на 90° (π/2 радиан) против часовой стрелки:
```
[0  -1  0]   [10]   [0]
[1   0  0] × [0 ] = [10]
[0   0  1]   [1 ]   [1 ]
```

Результат: `(0, 10)`

**Свойства:**
- Положительный угол - поворот против часовой стрелки
- Отрицательный угол - поворот по часовой стрелке
- Поворот относительно начала координат `(0, 0)`
- Сохраняет расстояния и углы

**Поворот относительно произвольной точки:**

Для поворота вокруг точки `(cx, cy)`:
1. Перенос на `(-cx, -cy)`
2. Поворот на угол `θ`
3. Перенос обратно на `(cx, cy)`

```
T_rotate_around_point = T_translate(cx, cy) × T_rotate(θ) × T_translate(-cx, -cy)
```

## Композиция трансформаций

### Последовательное применение

Трансформации применяются последовательно справа налево. Если нужно:
1. Сначала повернуть на угол `θ`
2. Затем масштабировать с коэффициентами `(sx, sy)`
3. Затем перенести на `(tx, ty)`

Результирующая матрица:
```
T = T_translate(tx, ty) × T_scale(sx, sy) × T_rotate(θ)
```

**Важно:** Порядок имеет значение! `A × B ≠ B × A` в общем случае.

### Пример композиции

Трансформация: поворот на 45°, масштабирование в 2 раза, перенос на (10, 5):

```
T_rotate(45°) = [0.707  -0.707  0]
                [0.707   0.707  0]
                [0       0      1]

T_scale(2, 2) = [2  0  0]
                [0  2  0]
                [0  0  1]

T_translate(10, 5) = [1  0  10]
                     [0  1  5 ]
                     [0  0  1 ]

T = T_translate(10, 5) × T_scale(2, 2) × T_rotate(45°)
```

## Обратная трансформация

Для перехода от координат изображения к реальным координатам (и наоборот) необходима обратная матрица.

Если `P' = T × P`, то `P = T⁻¹ × P'`

### Обратная матрица переноса

```
T_translate⁻¹(tx, ty) = T_translate(-tx, -ty)
```

### Обратная матрица масштабирования

```
T_scale⁻¹(sx, sy) = T_scale(1/sx, 1/sy)
```

### Обратная матрица поворота

```
T_rotate⁻¹(θ) = T_rotate(-θ)
```

### Обратная матрица композиции

Если `T = A × B × C`, то:
```
T⁻¹ = C⁻¹ × B⁻¹ × A⁻¹
```

**Важно:** Порядок обратных матриц обратный порядку исходных!

## Применение к изображениям

### Система координат изображения

В системе координат изображения:
- Начало координат `(0, 0)` обычно находится в левом верхнем углу
- Ось X направлена вправо
- Ось Y направлена вниз (в отличие от математической системы, где Y направлена вверх)

### Система координат реального пространства

В системе координат реального пространства (например, геодезической):
- Начало координат может быть в произвольной точке
- Ось X обычно направлена на восток
- Ось Y направлена на север (вверх)

### Матрица трансформации изображения → реальное пространство

Для преобразования координат из системы изображения в реальное пространство нужно учесть:

1. **Масштаб** - соотношение пикселей к единицам реального пространства
   - `sx = реальные_единицы_по_X / пиксели_по_X`
   - `sy = реальные_единицы_по_Y / пиксели_по_Y`

2. **Поворот** - угол поворота изображения относительно реальной системы координат
   - Обычно требуется поворот для выравнивания изображения

3. **Перенос** - смещение начала координат изображения в реальной системе
   - Координаты точки привязки (anchor point) в реальной системе

**Пример матрицы:**
```
T_image_to_real = T_translate(real_x, real_y) × T_rotate(θ) × T_scale(sx, sy)
```

Где:
- `(real_x, real_y)` - координаты точки привязки в реальной системе
- `θ` - угол поворота изображения
- `sx, sy` - масштабные коэффициенты

### Матрица трансформации реальное пространство → изображение

Для обратного преобразования (из реальных координат в координаты изображения):

```
T_real_to_image = T_image_to_real⁻¹
```

Или напрямую:
```
T_real_to_image = T_scale(1/sx, 1/sy) × T_rotate(-θ) × T_translate(-real_x, -real_y)
```

## Определение параметров трансформации

Для построения матрицы трансформации необходимо знать соответствие между точками в двух системах координат.

### Минимальное количество точек

Для полного определения 2D трансформации (6 параметров: 2 переноса, 1 поворот, 2 масштаба, 1 сдвиг) необходимо минимум 3 точки соответствия (control points).

### Метод решения

Если известны координаты точек в обеих системах:
- В системе изображения: `(x₁, y₁), (x₂, y₂), (x₃, y₃)`
- В реальной системе: `(X₁, Y₁), (X₂, Y₂), (X₃, Y₃)`

Можно решить систему уравнений для определения параметров матрицы трансформации.

### Упрощённые случаи

1. **Только масштаб и перенос** (без поворота):
   - Достаточно 2 точек соответствия
   - Матрица: `T = T_translate(tx, ty) × T_scale(sx, sy)`

2. **Равномерное масштабирование, поворот и перенос**:
   - Достаточно 2 точек соответствия
   - Матрица: `T = T_translate(tx, ty) × T_rotate(θ) × T_scale(s, s)`

## Построение матрицы трансформации по базовой точке и вектору

### Постановка задачи

Заданы следующие параметры:

1. **Базовая точка:**
   - Координаты в изображении: `(x0_image, y0_image)`
   - Фактические координаты (в системе CRS): `(x0_crs, y0_crs)`

2. **Вектор на изображении:**
   - Точки вектора в координатах изображения: `(x1, y1)` и `(x2, y2)`
   - Фактическая длина вектора: `L_real`
   - Фактический угол вектора (в системе CRS): `θ_real`

### Процесс трансформации

Трансформация выполняется в следующем порядке:

1. **Перенос** - перемещение базовой точки из `(x0_image, y0_image)` в `(x0_crs, y0_crs)`
2. **Поворот** - поворот изображения вокруг точки `(x0_crs, y0_crs)` на вычисленный угол
3. **Масштабирование** - масштабирование изображения относительно точки `(x0_crs, y0_crs)` с вычисленным коэффициентом

### Вычисление параметров трансформации

#### 1. Вычисление угла поворота

Вектор на изображении:
```
v_image = (x2 - x1, y2 - y1)
```

Угол вектора на изображении (в радианах):
```
θ_image = atan2(y2 - y1, x2 - x1)
```

Угол поворота, необходимый для выравнивания вектора изображения с фактическим направлением:
```
θ_rotate = θ_real - θ_image
```

**Примечание:** Угол `θ_real` задаётся в системе координат CRS, а `θ_image` вычисляется в системе координат изображения. При необходимости учитывайте разницу в направлении осей (Y вниз в изображении vs Y вверх в CRS).

#### 2. Вычисление коэффициента масштабирования

Длина вектора на изображении (в пикселях):
```
L_image = sqrt((x2 - x1)² + (y2 - y1)²)
```

Коэффициент масштабирования:
```
s = L_real / L_image
```

Если требуется равномерное масштабирование:
```
sx = sy = s
```

Если требуется независимое масштабирование по осям (например, при разных единицах измерения):
```
sx = L_real_x / L_image_x
sy = L_real_y / L_image_y
```

### Построение матрицы трансформации

#### Шаг 1: Перенос базовой точки

Перенос изображения так, чтобы базовая точка `(x0_image, y0_image)` оказалась в `(x0_crs, y0_crs)`:

```
T1 = T_translate(x0_crs - x0_image, y0_crs - y0_image)
```

После этого шага базовая точка изображения совпадает с точкой `(x0_crs, y0_crs)` в системе CRS.

#### Шаг 2: Поворот вокруг базовой точки

Поворот изображения вокруг точки `(x0_crs, y0_crs)` на угол `θ_rotate`:

```
T2 = T_rotate_around_point(x0_crs, y0_crs, θ_rotate)
```

Где:
```
T_rotate_around_point(cx, cy, θ) = T_translate(cx, cy) × T_rotate(θ) × T_translate(-cx, -cy)
```

#### Шаг 3: Масштабирование вокруг базовой точки

Масштабирование изображения относительно точки `(x0_crs, y0_crs)` с коэффициентом `s`:

```
T3 = T_scale_around_point(x0_crs, y0_crs, sx, sy)
```

Где:
```
T_scale_around_point(cx, cy, sx, sy) = T_translate(cx, cy) × T_scale(sx, sy) × T_translate(-cx, -cy)
```

#### Результирующая матрица

Полная матрица трансформации получается композицией всех трёх трансформаций:

```
T_image_to_crs = T3 × T2 × T1
```

Или в развёрнутом виде:

```
T_image_to_crs = T_scale_around_point(x0_crs, y0_crs, sx, sy) 
                × T_rotate_around_point(x0_crs, y0_crs, θ_rotate)
                × T_translate(x0_crs - x0_image, y0_crs - y0_image)
```

### Развёрнутая формула

Подставляя определения трансформаций относительно точки, получаем:

```
T_image_to_crs = T_translate(x0_crs, y0_crs) 
                × T_scale(sx, sy) 
                × T_translate(-x0_crs, -y0_crs)
                × T_translate(x0_crs, y0_crs) 
                × T_rotate(θ_rotate) 
                × T_translate(-x0_crs, -y0_crs)
                × T_translate(x0_crs - x0_image, y0_crs - y0_image)
```

Упрощая (последовательные переносы объединяются):

```
T_image_to_crs = T_translate(x0_crs, y0_crs) 
                × T_scale(sx, sy) 
                × T_rotate(θ_rotate) 
                × T_translate(-x0_image, -y0_image)
```

### Алгоритм построения матрицы

1. Вычислить вектор на изображении: `v_image = (x2 - x1, y2 - y1)`
2. Вычислить угол вектора на изображении: `θ_image = atan2(y2 - y1, x2 - x1)`
3. Вычислить длину вектора на изображении: `L_image = ||v_image||`
4. Вычислить угол поворота: `θ_rotate = θ_real - θ_image`
5. Вычислить коэффициент масштабирования: `s = L_real / L_image`
6. Построить матрицу переноса: `T1 = T_translate(x0_crs - x0_image, y0_crs - y0_image)`
7. Построить матрицу поворота: `T2 = T_rotate_around_point(x0_crs, y0_crs, θ_rotate)`
8. Построить матрицу масштабирования: `T3 = T_scale_around_point(x0_crs, y0_crs, s, s)`
9. Вычислить результирующую матрицу: `T = T3 × T2 × T1`

### Пример

**Исходные данные:**
- Базовая точка изображения: `(100, 200)` пикселей
- Базовая точка CRS: `(5000, 6000)` метров
- Вектор на изображении: от `(100, 200)` до `(300, 400)` пикселей
- Фактическая длина вектора: `100` метров
- Фактический угол вектора: `45°` (π/4 радиан)

**Вычисления:**

1. Вектор на изображении: `v_image = (200, 200)` пикселей
2. Угол вектора на изображении: `θ_image = atan2(200, 200) = π/4` радиан
3. Длина вектора на изображении: `L_image = sqrt(200² + 200²) = 200√2 ≈ 282.8` пикселей
4. Угол поворота: `θ_rotate = π/4 - π/4 = 0` (вектор уже направлен правильно)
5. Коэффициент масштабирования: `s = 100 / 282.8 ≈ 0.354` метров/пиксель

**Матрицы:**

```
T1 = T_translate(5000 - 100, 6000 - 200) = T_translate(4900, 5800)

T2 = T_rotate_around_point(5000, 6000, 0) = единичная матрица

T3 = T_scale_around_point(5000, 6000, 0.354, 0.354)
```

**Результирующая матрица:**
```
T = T3 × T2 × T1
```

### Обратная трансформация

Для преобразования координат из системы CRS в координаты изображения:

```
T_crs_to_image = T_image_to_crs⁻¹
```

Или, используя свойства обратных матриц:

```
T_crs_to_image = T_translate(x0_image, y0_image)
                × T_rotate(-θ_rotate)
                × T_scale(1/sx, 1/sy)
                × T_translate(-x0_crs, -y0_crs)
```

### Важные замечания

1. **Порядок операций:** Порядок трансформаций (перенос → поворот → масштабирование) важен. Изменение порядка даст другой результат.

2. **Система координат изображения:** Учитывайте, что в системе координат изображения ось Y направлена вниз. При вычислении углов может потребоваться коррекция.

3. **Единицы измерения:** Убедитесь, что единицы измерения длины вектора на изображении (пиксели) и фактической длины (метры, футы и т.д.) согласованы.

4. **Точность:** При вычислении углов и длин используйте достаточную точность, особенно при работе с большими координатами.

## Практические соображения

### Точность вычислений

- Использовать достаточную точность для углов (радианы с высокой точностью)
- Учитывать ошибки округления при последовательных трансформациях
- При необходимости использовать двойную точность

### Производительность

- Предвычислять матрицу трансформации один раз
- Применять матрицу ко всем точкам батчами
- Использовать оптимизированные библиотеки для матричных операций (например, NumPy)

### Обработка границ

- При трансформации изображения могут появляться области за пределами исходных границ
- Необходимо учитывать выход за границы при обратной трансформации
- Проверять валидность результирующих координат
